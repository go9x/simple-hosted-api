Simple Hosted API

Version 1.0.0

A simple REST API for user management demonstration.

Base URL: https://simple-hosted-api.vercel.app

Endpoints

GET /

Returns API information and a list of available endpoints.

Example Request
curl https://simple-hosted-api.vercel.app/
Response 200
{
  "message": "Welcome to the Simple Hosted API!",
  "version": "1.0.0",
  "endpoints": {
    "GET /": "This message",
    "GET /docs": "API documentation (HTML)",
    "GET /users": "Get all users",
    "GET /users/:id": "Get a specific user",
    "POST /users": "Create a new user",
    "GET /status": "API status"
  }
}
GET /users

Returns a list of all users.

Example Request
curl https://simple-hosted-api.vercel.app/users
Response 200
{
  "success": true,
  "data": [
    { "id": 1, "name": "John Doe", "email": "john@example.com" },
    { "id": 2, "name": "Jane Smith", "email": "jane@example.com" },
    { "id": 3, "name": "Bob Johnson", "email": "bob@example.com" }
  ],
  "count": 3
}
GET /users/:id

Returns a specific user by their ID.

URL Parameters
id integer required - The user's ID
Example Request
curl https://simple-hosted-api.vercel.app/users/1
Response 200
{
  "success": true,
  "data": {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
  }
}
Error Response 404
{
  "success": false,
  "message": "User not found"
}
POST /users

Creates a new user.

Request Body (JSON)
name string required - The user's name
email string required - The user's email address
Example Request
curl -X POST https://simple-hosted-api.vercel.app/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Alice Cooper", "email": "alice@example.com"}'
Response 201
{
  "success": true,
  "message": "User created successfully",
  "data": {
    "id": 4,
    "name": "Alice Cooper",
    "email": "alice@example.com"
  }
}
Error Response 400
{
  "success": false,
  "message": "Name and email are required"
}
GET /status

Returns the API health status and uptime information.

Example Request
curl https://simple-hosted-api.vercel.app/status
Response 200
{
  "status": "healthy",
  "timestamp": "2026-01-06T12:00:00.000Z",
  "uptime": 123.456,
  "environment": "production"
}
